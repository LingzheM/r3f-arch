M2 墙角严丝合缝

画一个矩形房间，四个墙角像真的一样对齐——没有十字穿模，没有缺口， 内角和外角各自落在该在的位置。再画一个 T 型隔断，撞上去的墙自动切齐。

M1 的每一堵墙都是孤岛。M2 之后它们互相知道对方的存在—— 这是整个项目里第一次出现"节点几何依赖场景全局状态"， 也是后面所有难题（层高传播、门窗开洞、屋顶裁切）的同一个形状。

01这一步在解决什么

一个签名的改变，撬动整条数据流

M2 的全部难度可以压缩成一行签名的变化：

// M1
buildWallGeometry(wall: WallNode): BufferGeometry

// M2
buildWallGeometry(wall: WallNode, miter: MiterData): BufferGeometry
                                  ^^^^^^^^^^^^^^^^^ 这个参数来自「所有墙」

多出来的那个参数不是一个普通依赖。它意味着你不能再孤立地渲染一个节点—— 必须先有一趟全局计算，再有逐节点的几何生成。这一个改动会连锁出四件事， 每一件都是这个项目里反复出现的模式：

  1. 两阶段渲染。先算 miter（一次，全局），再建几何（N 次，逐墙）。 原项目的 <GeometrySystem> 就是这个模式的成熟形态。
  2. 失效范围。改一堵墙，要重算哪些？答案是"它自己 + 共享交点的邻居"。 原项目为此专门有个 getAdjacentWallIds()。M2 先全量重算， M3 才做脏传播——但你现在就要知道这个问题存在。
  3. 拓扑判据。"两堵墙接在一起"不是浮点相等，是 量化到同一个毫米格。这个判据一旦定下，整个项目都得用它。
  4. 纯度的回报。整个斜接算法没有一行 three——它是纯二维几何。 所以它住在 core，可以在 Node 里裸测。 M1 那条"core 不许 import three"的铁律，第一次真正付了息。

M2 结束时你能做到

  • 画一个封闭矩形房间，四角严丝合缝，顶视图看不到任何十字叠加或缺口
  • 画一个 T 型：一堵墙撞到另一堵墙的中间，撞上来的那堵被切齐
  • 改任意一堵墙的厚度，相邻墙角自动跟着重算
  • 两堵墙夹角小到 1°，不会射出无限长的尖刺

02斜接算法

五步，核心不到 200 行

原项目 packages/core/src/systems/wall/wall-mitering.ts 是 536 行， 但其中一半是曲线墙、空间网格加速、T 型排序稳定性。剥掉之后，算法本体是这五步。 先把这一节读懂再动手——它是 M2 唯一需要理解的东西，剩下都是打字。

① 找交点

把每堵墙的两个端点扔进一个哈希桶，key 是量化后的坐标字符串。 两堵墙的端点落进同一个桶，就是一个交点。然后第二遍扫描找 T 型： 某个交点落在另一堵墙的身上（不含端点），那堵墙以 passthrough 的身份也加入这个交点。最后丢掉只有一堵墙的桶——那是自由端。

② 把每堵墙变成两条边线

对交点处的每堵墙，取从交点出发的方向向量 v， 算出左右两条边线（中心线 ± 半厚，沿 v 延伸）。 直线用一般式 ax + by + c = 0 存，因为下一步要解线性方程组。

T 型里那堵"被撞"的直墙要贡献两条腿（v 和 −v）—— 对撞上来的墙而言，它是左右两个方向上的邻居。

③ 按角度排序，环形配对

所有腿按出射角 atan2(v.y, v.x) 升序排。然后 legs[i] 与 legs[(i+1) % n] 配对—— 相邻两条腿之间夹着一个楔形空隙，那就是要被斜接填掉的地方。

④ 求交点

楔形由前一条腿的左边线和后一条腿的右边线围成。 两线求交，得到的就是墙角的尖点。写回时：前者拿 left，后者拿 right。 passthrough 的腿不写回——被撞的那堵直墙，几何不该被改。

⑤ 取用时左右互换

getWallMiterBoundaryPoints(wall, miterData) 从交点数据里取四个角。 这里藏着 M2 最容易调半天的一处，见下面的算例。

取用时必须这样写，注意后两行的交叉：

startLeft  ← startJunction.left
startRight ← startJunction.right
endLeft    ← endJunction.right     // 交叉！
endRight   ← endJunction.left      // 交叉！

为什么：在 end 交点处，这堵墙的出射方向是反的， 所以它的"左"也就反了。用上面的算例验证——墙 A 沿 +X，它的 left 侧应该是 y > 0。endJunction.right = (3.9, 0.1)，y 是正的 ✓。 不交叉的话你会拿到 (4.1, −0.1)，跑到右侧去了。

症状：矩形房间的四个角，两个对角是尖的，另两个凹进去， 而且轮廓自交、挤出后的面撕裂。这个 bug 只在转角出现，直墙全对， 所以你会先怀疑一百个别的地方。

这个练习的全部价值在这一刻

按上面 2N 个顶点的写法跑起来，你会看到墙的棱角是糊的—— 光照像被抹过，方盒子看着像块肥皂。

computeVertexNormals() 把共享同一顶点的所有面的法线做平均。 墙角那个顶点同时属于两个侧面和一个顶面，三个互相垂直的法线一平均， 得到斜向 45° 的法线 —— 硬边就被渲染成了圆角。

修法只有一个：不共享。每个面拥有自己的顶点。 一堵四边形墙的棱柱因此需要 24 个顶点 （4 个侧面 × 4 + 上下盖 × 4），不是 8 个。 这就是你要拿走的东西。

③ 跑通、比对、删除

画一堵墙，确认画面和 M1 的 Box 版一模一样——没有肉眼比对， 你写的顶点数组对不对完全无从判断。确认后进入第 02 步； 等第 09 步换成 ExtrudeGeometry 之后， git rm src/viewer/lib/prism-by-hand.ts。

那个"24 而不是 8"的认知，有三个直接的下游后果，全在后面等着：

  • 第 09 步 —— ExtrudeGeometry 吐出的顶点数远多于轮廓点数。 你会知道那不是浪费，是必须。
  • M4 材质槽位 —— 一堵墙内外面贴不同材质，靠 geometry.groups 按顶点区间切分。顶点不独立就切不开。
  • M6 CSG —— 原项目那句 geometry.toNonIndexed() 的注释写着 "so every triangle projects by its own face normal (no shared-vertex seams at edges)"，说的就是这件事。

能不能跳过？能。代价是 M4 调材质分组、M6 调 CSG 时， 你面对一堆 Float32Array 和 groups 索引却没有直觉，只能试。 我的判断是别跳——它只花两小时，而且是整个六阶段里唯一一次 被迫直面 position / normal / uv / index 的机会，后面全是库替你生成。

/** 直线的一般式 ax + by + c = 0。
 *  为什么不用「点 + 方向」？因为求交要解 2×2 线性方程组，
 *  一般式的系数直接就是系数矩阵。 */
export type Line = { a: number; b: number; c: number }

export function lineFromPointAndDirection(p: Point2D, v: Point2D): Line {
  const a = -v.y
  const b = v.x
  return { a, b, c: -(a * p.x + b * p.y) }
}

/** 两直线求交。平行返回 null。 */
export function intersectLines(l1: Line, l2: Line): Point2D | null {
  const det = l1.a * l2.b - l2.a * l1.b
  if (Math.abs(det) < EPSILON) return null
  // 克拉默法则。y 的分子是 (a2·c1 − a1·c2)，符号很容易抄反 ——
  // 抄反的表现是：墙角位置对，但左右镜像。
  return {
    x: (l1.b * l2.c - l2.b * l1.c) / det,
    y: (l2.a * l1.c - l1.a * l2.c) / det,
  }
}

/** 点是否落在线段「身上」（不含两端）。T 型接头的判据。 */
export function pointOnSegment(p: Point2D, a: Point2D, b: Point2D, tol = 1e-3): boolean {
  const ab = sub(b, a)
  const L2 = ab.x * ab.x + ab.y * ab.y
  if (L2 < EPSILON) return false
  const L = Math.sqrt(L2)
  const ap = sub(p, a)

  // ① 投影参数落在开区间内。容差要除以长度换算到 t 空间 ——
  //    tol 的单位是米，t 是无量纲比例。原项目直接拿 tol 当 t 的容差用，
  //    在 4 米长的墙上等于 4 毫米，能用但不严谨。
  const t = (ab.x * ap.x + ab.y * ap.y) / L2
  const tTol = tol / L
  if (t <= tTol || t >= 1 - tTol) return false

  // ② 到直线的垂距。只判 ① 会把远处平行的点误判成 T 接。
  return Math.abs(ab.x * ap.y - ab.y * ap.x) / L < tol
}

/** 量化坐标 → 字符串键。整个 M2 的地基：
 *  「两堵墙接在一起」的判据不是浮点相等，是量化到同一个毫米格。 */
export function quantizeKey(p: Point2D, tol = 1e-3): string {
  return `${Math.round(p.x / tol)},${Math.round(p.y / tol)}`
}

function findJunctions(walls: WallNode[]): Map<string, Junction> {
  const buckets = new Map<string, Junction>()

  const push = (p: Point2D, wall: WallNode, endType: EndType) => {
    const key = quantizeKey(p, JUNCTION_TOLERANCE)
    let j = buckets.get(key)
    if (!j) { j = { meetingPoint: p, connected: [] }; buckets.set(key, j) }
    j.connected.push({ wall, endType })
  }

  // 第一遍：每堵墙的两个端点各入桶
  for (const wall of walls) {
    push(wallStart(wall), wall, 'start')
    push(wallEnd(wall), wall, 'end')
  }

  // 第二遍：T 型 —— 交点落在某堵墙「身上」
  // 按 walls 的输入顺序遍历，追加顺序才是确定的。共线的两堵墙在下面
  // 排序时角度会打平，稳定排序保留追加顺序 —— 顺序不定就会随机选错厚度。
  // 复杂度 O(交点数 × 墙数)。原项目 1081 堵墙时实测 584ms，2 米网格分桶降到 11ms。
  // M2 不做这个优化 —— 你只有几十堵墙。M3 的性能课会回来找这行注释。

    for (const wall of walls) {
      if (junction.connected.some((c) => c.wall.id === wall.id)) continue
      if (pointOnSegment(junction.meetingPoint, wallStart(wall), wallEnd(wall), JUNCTION_TOLERANCE)) {
        junction.connected.push({ wall, endType: 'passthrough' })
      }
    }

  for (const [key, j] of buckets) if (j.connected.length >= 2) result.set(key, j)

function legsAtJunction(
  wall: WallNode, endType: EndType, meetingPoint: Point2D, halfT: number,
): Leg[] {
  const forward = sub(wallEnd(wall), wallStart(wall))

  // 方向必须是「从交点出发」：
  //   start       → end - start
  //   end         → start - end   （取反！搞反了整个环形排序就乱了）
  //   passthrough → 两条腿，因为被撞的直墙对撞上来的墙而言是左右两侧的邻居
  const dirs =
    endType === 'passthrough' ? [forward, scale(forward, -1)]
    : endType === 'start'     ? [forward]
    :                           [scale(forward, -1)]

  const legs: Leg[] = []
  for (const v of dirs) {
    if (len(v) < EPSILON) continue
    const n = scale(leftNormal(v), halfT)
    legs.push({
      wallId: wall.id,
      angle: Math.atan2(v.y, v.x),
      edgeLeft:  lineFromPointAndDirection(add(meetingPoint, n), v),
      edgeRight: lineFromPointAndDirection(sub(meetingPoint, n), v),
      isPassthrough: endType === 'passthrough',
      halfThickness: halfT,
    })
  }
  return legs
}

// ── ③④ 排序、环形配对、求交 ──────────────────────────

function calculateJunctionIntersections(junction: Junction): Map<string, MiterCorner> {
  const legs: Leg[] = []
  for (const { wall, endType } of junction.connected) {
    legs.push(...legsAtJunction(wall, endType, junction.meetingPoint, getWallThickness(wall) / 2))
  }

  // 角度相同时按 wallId 排 —— 保证同一份场景每次算出逐位相同的结果。
  // 否则 Map 迭代顺序会让墙角在两次渲染之间抖动。
  legs.sort((p, q) =>
    p.angle !== q.angle ? p.angle - q.angle
    : p.wallId < q.wallId ? -1 : p.wallId > q.wallId ? 1 : 0)

  const out = new Map<string, MiterCorner>()
  const n = legs.length
  if (n < 2) return out

  const cornerOf = (id: string): MiterCorner => {
    let c = out.get(id)
    if (!c) { c = {}; out.set(id, c) }
    return c
  }

  for (let i = 0; i < n; i++) {
    const a = legs[i]!
    const b = legs[(i + 1) % n]!

    // 相邻两条腿之间夹着一个楔形空隙，由 a 的左边和 b 的右边围成。
    // 画个图确认这个配对方向，别硬记。
    const p = intersectLines(a.edgeLeft, b.edgeRight)
    if (!p || !Number.isFinite(p.x) || !Number.isFinite(p.y)) continue

    // miter limit：det 只挡得住严格平行。夹角很小的两堵墙 det 小而非零，
    // 交点会落到很远的地方。超出就回退平接。
    const maxMiter = MITER_LIMIT * Math.max(a.halfThickness, b.halfThickness)
    const dx = p.x - junction.meetingPoint.x
    const dy = p.y - junction.meetingPoint.y
    if (dx * dx + dy * dy > maxMiter * maxMiter) continue

    // passthrough 的腿不写回 —— T 型里被撞的直墙，几何不该被改。
    if (!a.isPassthrough) cornerOf(a.wallId).left = p
    if (!b.isPassthrough) cornerOf(b.wallId).right = p
  }

  return out
}

import * as THREE from 'three'
import type { Point2D } from '../../core/lib/geometry-2d'

/** 鞋带公式：轮廓在 (x, z) 上的有符号面积。>0 逆时针，<0 顺时针。 */
function signedArea(fp: Point2D[]): number {
  let s = 0
  for (let i = 0; i < fp.length; i++) {
    const a = fp[i]!, b = fp[(i + 1) % fp.length]!
    s += a.x * b.y - b.x * a.y
  }
  return s / 2
}

/** 本文件约定：轮廓归一化成 (x,z) 顺时针。在这个约定下侧面按
 *  (底i, 底j, 顶j) 绕出来法线朝外，顶面按原序绕出来朝 +Y。 */
const toClockwise = (fp: Point2D[]) => (signedArea(fp) > 0 ? [...fp].reverse() : fp)

// ── ❶ 先写这个：2N 个顶点，侧面和顶底面共享。跑起来看糊棱角。 ──
export function buildPrismNaive(footprint: Point2D[], height: number): THREE.BufferGeometry {
  const geometry = new THREE.BufferGeometry()
  if (footprint.length < 3) return geometry

  const fp = toClockwise(footprint)
  const n = fp.length

  const positions: number[] = []
  for (const p of fp) positions.push(p.x, 0,      p.y)   // 0 .. n-1    底环
  for (const p of fp) positions.push(p.x, height, p.y)   // n .. 2n-1   顶环
  //                                       ↑ 局部 Y 从 0 到 height（M2 新约定）

  const indices: number[] = []
  for (let i = 0; i < n; i++) {
    const j = (i + 1) % n
    indices.push(i, j, n + j,  i, n + j, n + i)          // 侧面两个三角形
  }
  // 扇形三角剖分，只对凸多边形成立 —— 这也是 M4 带洞轮廓不能这么剖的原因
  for (let i = 1; i < n - 1; i++) indices.push(n, n + i, n + i + 1)   // 顶
  for (let i = 1; i < n - 1; i++) indices.push(0, i + 1, i)           // 底（绕向相反）

  geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3))
  geometry.setIndex(indices)
  geometry.computeVertexNormals()   // 先注释掉跑一次 —— 墙全黑
  return geometry
}

// ── ❷ 修法：每个面独立顶点。4 边形墙 = 4×4 + 4 + 4 = 24 个顶点。 ──
export function buildPrismByHand(footprint: Point2D[], height: number): THREE.BufferGeometry {
  const geometry = new THREE.BufferGeometry()
  if (footprint.length < 3) return geometry

  const fp = toClockwise(footprint)
  const n = fp.length
  const positions: number[] = []
  const uvs: number[] = []
  const indices: number[] = []

  let uRun = 0                                   // 沿墙累计弧长 → U 坐标
  for (let i = 0; i < n; i++) {
    const a = fp[i]!, b = fp[(i + 1) % n]!
    const edgeLen = Math.hypot(b.x - a.x, b.y - a.y)
    const base = positions.length / 3

    positions.push(
      a.x, 0,      a.y,    // base+0 左下
      b.x, 0,      b.y,    // base+1 右下
      b.x, height, b.y,    // base+2 右上
      a.x, height, a.y,    // base+3 左上
    )
    // 1 uv 单位 = 1 米。U 沿墙长累计，贴图跨过转角能接上。
    // 先注释掉这四行跑一次 —— uv 全 0，贴图变成「一个像素拉满整面墙」。
    uvs.push(uRun, 0,  uRun + edgeLen, 0,  uRun + edgeLen, height,  uRun, height)

    indices.push(base, base + 1, base + 2,  base, base + 2, base + 3)
    uRun += edgeLen
  }

  // 顶面。面内共享顶点是安全的 —— 同一平面法线本来就相同，平均等于不变。
  // 「共享」的危险只发生在跨越折角时。
  const topBase = positions.length / 3
  for (const p of fp) { positions.push(p.x, height, p.y); uvs.push(p.x, p.y) }
  for (let i = 1; i < n - 1; i++) indices.push(topBase, topBase + i, topBase + i + 1)

  const botBase = positions.length / 3
  for (const p of fp) { positions.push(p.x, 0, p.y); uvs.push(p.x, p.y) }
  for (let i = 1; i < n - 1; i++) indices.push(botBase, botBase + i + 1, botBase + i)

  geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3))
  geometry.setAttribute('uv',       new THREE.Float32BufferAttribute(uvs, 2))
  geometry.setIndex(indices)
  geometry.computeVertexNormals()
  return geometry
}

import * as THREE from 'three'
import { midpoint, type Point2D } from '../../core/lib/geometry-2d'
import { getWallHeight, wallEnd, wallStart, type WallNode } from '../../core/schema/wall'
import { getWallPlanFootprint } from '../../core/systems/wall/wall-footprint'
import type { MiterData } from '../../core/systems/wall/wall-mitering'

/** 世界 XZ 点 → mesh 局部 XZ 点。
 *  mesh 的 local→world 是「先绕 Y 转 rotationY，再平移 position」，逆变换即：
 *    绕 Y 转 θ： (lx,lz) → ( lx·cosθ + lz·sinθ, −lx·sinθ + lz·cosθ )
 *    逆：        (dx,dz) → ( dx·cosθ − dz·sinθ,  dx·sinθ + dz·cosθ ) */
export function worldToLocalXZ(
  p: Point2D, position: [number, number, number], rotationY: number,
): Point2D {
  const cos = Math.cos(rotationY)
  const sin = Math.sin(rotationY)
  const dx = p.x - position[0]
  const dz = p.y - position[2]          // p.y 是世界 Z
  return { x: dx * cos - dz * sin, y: dx * sin + dz * cos }
}

export function wallTransform(wall: WallNode): {
  position: [number, number, number]
  rotationY: number
} {
  const start = wallStart(wall)
  const end = wallEnd(wall)
  const c = midpoint(start, end)

  // 推导见 M1：Box/挤出体的长边沿局部 +X，绕 Y 正转把 +X 转向 −Z，
  // 所以 θ = atan2(−dz, dx)。少个负号 = 斜墙镜像，直墙全对。
  const rotationY = Math.atan2(-(end.y - start.y), end.x - start.x)

  // M2 改：y 从 height/2 改成 0 —— 挤出体天然占 [0, height]，
  // 而「墙底在局部原点」才是 M5 层高标高的正确基准。
  return { position: [c.x, 0, c.y], rotationY }
}

export function buildWallGeometry(wall: WallNode, miter: MiterData): THREE.BufferGeometry {
  // ① 世界坐标的斜接轮廓
  const worldFp = getWallPlanFootprint(wall, miter)
  if (worldFp.length < 3) return new THREE.BufferGeometry()

  // ② 转局部。为什么不直接用世界坐标建几何、让 mesh 不做变换？
  //    因为 M3 的拖拽要靠 mutate Object3D.position 来避免重建几何。
  //    几何一旦是世界坐标的，拖一下就得重算轮廓 —— 那条性能路径就断了。
  const { position, rotationY } = wallTransform(wall)
  const local = worldFp.map((p) => worldToLocalXZ(p, position, rotationY))

  // ③ Shape 活在 XY 平面。那个负号：rotateX(−π/2) 会把 (x,y,z) 映成 (x,z,−y)，
  //    即 shape 的 y 变成几何的 −z。所以填的时候先取反，转完正好抵消。
  //    绕向不用管 —— ExtrudeGeometry 内部会 isClockWise() + reverse() 归一化。
  const shape = new THREE.Shape()
  shape.moveTo(local[0]!.x, -local[0]!.y)
  for (let i = 1; i < local.length; i++) shape.lineTo(local[i]!.x, -local[i]!.y)
  shape.closePath()

  // ④ 沿 +Z 挤出 height
  const geometry = new THREE.ExtrudeGeometry(shape, {
    depth: getWallHeight(wall),
    bevelEnabled: false,
  })

  // ⑤ 把挤出方向掰成竖直。rotateX 会用法线矩阵把 normal 一起转过去，
  //    所以不需要再调 computeVertexNormals()。
  geometry.rotateX(-Math.PI / 2)
  return geometry
}
